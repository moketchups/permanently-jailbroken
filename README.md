# Can AI Audit Itself?

5 questions. 6 AI architectures. Run it yourself.

```bash
git clone https://github.com/moketchups/five-question-probe
cd five-question-probe
pip install -r requirements.txt
cp .env.example .env    # add your API keys
python run_probe.py
```

~$2 in API credits. ~10 minutes. Read the questions in [`run_probe.py`](./run_probe.py) — they're short.

Sample results from our run are in [`results/sample/`](./results/sample/).

---

**Context:** These questions are distilled from [a longer experiment](https://github.com/moketchups/BoundedSystemsTheory).
